# Saiboard 硬件开发与生产指南

本指南旨在帮助开发者了解 Saiboard 项目中的工业生产模型，掌握相关软件工具的使用，并指导如何将设计转化为实物。

## 1. 硬件模型概览与背景知识

项目中的硬件设计分为三个核心部分：

### 1.1 棋盘结构 (Board Structure)
*   **模型位置**: `board/cnc_files/`（CNC/激光切割文件）, `board/3d_prints/`（辅助工具）
*   **文件格式**: `.f3d` (Fusion 360 源文件), `.dxf` (2D 矢量，直接发给加工厂)
*   **参考图片**: `board/board.jpg`（组装实物照片）
*   **背景知识**:
    *   **木工与 CNC**: 棋盘框架由胶合板加工而成。`.dxf` 文件用于激光切割或 CNC 铣削。
    *   **公差 (Tolerance)**: 硬件设计中必须考虑零件组装时的间隙，否则无法物理嵌入。
    *   **层叠结构**: 棋盘由 4 层木板叠合，形成空腔容纳电子元件（详见 4.1 节）。
*   **软件**: **Autodesk Fusion 360**（编辑 `.f3d`）, **AutoCAD / Inkscape**（查看 `.dxf`）。
*   **作用**: 定义棋盘的物理外观、尺寸、传感器排布以及各部件的连接方式。

#### 木皮选材建议

木皮贴在顶层面板上方，LED 灯光需要透过木皮漫射出来，因此**透光性**是选材的核心考量。推荐选择浅色、纹理均匀的树种：

| 树种 | 优点 | 缺点 |
| :--- | :--- | :--- |
| 榧木 (Kaya) | 围棋盘传统用材，色泽温润，纹理细腻 | 价格极高 |
| 新榧 / 云杉 (Shin-Kaya / Spruce) | 颜色与榧木接近，浅黄色，透光性好，价格合理 | 纹理相对普通 |
| 桧木 (Hinoki) | 日式棋盘常用，颜色浅，质地均匀 | 有些品种纹理不够直 |
| 枫木 (Maple) | 颜色浅白，纹理均匀，透光效果好，易获取 | 非传统围棋盘用材 |
| 桦木 (Birch) | 浅色，纹理细密，0.6mm 时透光性好 | 非传统围棋盘用材 |

> **不推荐：** 胡桃木、黑檀等深色木材会严重阻挡 LED 光线；橡木等导管粗大的木材透光不均匀，且针管笔画线时墨水容易沿导管渗开。

> **建议：** 综合透光性、外观和性价比，**新榧（云杉类）或枫木**是较优选择。购买前建议先取一小块样品测试 LED 透光效果。

#### 制作步骤

**第一阶段：CNC / 激光切割**

1. 将 4 个 `.dxf` 文件（`top.dxf`, `grid.dxf`, `side.dxf`, `bottom.dxf`）发给加工厂或导入自有 CNC/激光设备。
2. **务必确认单位为毫米 (mm)**，防止比例缩放错误。
3. 按对应板厚裁切：顶层和网格层 6.5mm、侧框 10mm、底板 5mm。
4. 告知加工师傅区分"切断"和"雕刻"（如果有浅雕线条）。

**第二阶段：木框粘合**

1. 将 **底板**、**侧框**、**网格层** 三层对齐叠放，用木工胶粘合。
2. 使用木工夹夹紧，**静置过夜**等胶水完全固化。
3. 打磨接合面，确保各层平整无错位。

> **注意：** 此阶段**不粘顶层面板**，因为需要先安装电子元件（见 4.2 节步骤三），最后再盖上顶层。

**第三阶段：顶层面板处理**

1. 裁切一块 0.6mm 木皮，面积略大于顶层面板。
2. 在面板表面和木皮背面各涂一层木工胶，**晾至半干**（不粘手但有粘性）。
3. 将木皮覆盖到面板上，用熨斗加热压实，使胶水重新活化并牢固粘合。
4. 待冷却后，用刀片或砂纸修剪木皮至与面板齐平。
5. （可选）轻涂一层木蜡油（Oil finish）作为初步保护。

**第四阶段：灌注树脂**

1. 将木框（底板+侧框+网格层）翻转，使 LED 孔朝上。
2. 从**内侧**向 361 个 LED 孔灌入透明环氧树脂，覆盖孔洞即可。
3. 用喷枪消除气泡，静置固化（24 小时）。
4. 树脂固化后，LED 光线将通过木皮漫射，形成柔和的透光效果。

**第五阶段：表面涂装**

1. 在顶层面板表面涂刷第 1 层**聚氨酯漆**（擦涂式 Wipe-on Poly），薄涂均匀。
2. 干燥后用 320 目砂纸轻磨，擦净粉尘。
3. 重复涂刷共 **4 层**（每层之间轻磨）。
4. 最终表面应光滑、有轻微光泽、具备防水防污能力。

**第六阶段：绘制棋盘网格线**

1. 组装 CNC 弹簧笔架：3D 打印 `pen_part1.f3d` 和 `pen_part2.f3d`，配合弹簧组装（参考 [Instructables 弹簧笔架教程](https://www.instructables.com/Spring-loaded-CNC-Penholder-for-Rapidograph-techni/)）。
2. 将 rOtring Isograph 0.8mm 针管笔装入笔架，安装到 CNC 机器上。
3. 用 CNC 自动绘制 19×19 网格线（直线部分）。
4. **星位 (Star Points)** 需手工点绘——标准 19×19 棋盘有 9 个星位。
5. 网格线完成后，再涂刷 1-2 层聚氨酯漆封住墨线，防止磨损。

> **提示：** 如果没有 CNC 设备，也可以用直尺和针管笔手工绘制网格线，但需要极高的精度和耐心。

### 1.2 电子系统 (Electronics)
*   **模型位置**: `electronics/kicad_files/`, `electronics/3d_prints/`
*   **文件格式**: `.kicad_sch` / `.kicad_pcb` (KiCad), `.f3d`
*   **背景知识**:
    *   **PCB 设计**: 涉及电路原理图和印刷电路板布线。
    *   **霍尔传感器 (Hall Effect Sensor)**: 项目核心硬件，用于通过磁性检测棋子位置。
    *   **3D 打印遮罩**: 用于辅助固定传感器或遮挡光线。
*   **软件**: **KiCad**, **Fusion 360**。
*   **作用**: KiCad 负责电路逻辑和 PCB 生产；Fusion 360 负责设计 PCB 的支撑结构和外壳。

#### PCB 子板拼接布局 (19×19 Matrix Tiling)

完整的 19×19 传感器/LED 矩阵由 **8 块 PCB 子板**拼接而成（19 = 8 + 8 + 3）。

> 📐 **交互式高清示意图**：[pcb-tiling-diagram.html](pcb-tiling-diagram.html)（浏览器打开，包含连接器颜色编码、信号标注和拼接方式图解）

文本版布局如下：

```
         列1──────8  列9─────16  列17─19
        ┌─────────┬──────────┬────────┐
        │         │          │        │
 行     │  8 × 8  │  8 × 8   │ 3 × 8  │
 1      │  (64)   │  (64)    │ (24)   │
 ↓      │         │          │        │
 8      │   ①     │   ②      │  ③     │
        ├─────────┼──────────┼────────┤
        │         │          │        │
 行     │  8 × 8  │  8 × 8   │ 3 × 8  │
 9      │  (64)   │  (64)    │ (24)   │
 ↓      │         │          │        │
 16     │   ④     │   ⑤      │  ⑥     │
        ├─────────┴──────────┼────────┤
 行     │                    │        │
 17     │     11 × 3         │ 8 × 3  │
 ↓      │     (33)           │ (24)   │
 19     │       ⑦            │  ⑧     │
        └────────────────────┴────────┘
```

| :--- | :--- | :--- | :--- | :--- |
| 8×8 | 4 | 64 | 256 | `electronics/kicad_files/8x8/` |
| 3×8 | 2 | 24 | 48 | `electronics/kicad_files/3x8/` |
| 11×3 | 1 | 33 | 33 | `electronics/kicad_files/11x3/` |
| 8×3 | 1 | 24 | 24 | `electronics/kicad_files/8x3/` |
| **合计** | **8 块** | | **361** | |

*   ⑦号 11×3 板横跨列1-11（覆盖了左下角区域），避免了需要一块独立的 3×3 小板。
*   各子板通过排针/排母连接器（PQ、Hall、LED、Touch、Power）互联。

#### 子板边缘连接器详解

每块子板（以 8×8 为例）的四条边分布着不同类型的连接器，所有连接器均为 **2.54mm 间距卧贴 SMD** 封装：

| 边 | 连接器类型 | 数量与规格 | 传递信号 |
| :--- | :--- | :--- | :--- |
| **上边 (Top)** | 公头 (PinHeader) | 1×02 × 4 组 + 1×02 × 1 | Hall 输出 (HallOut1-8) + LED 数据输入 |
| **下边 (Bottom)** | 母头 (PinSocket) | 1×02 × 4 组 + 1×02 × 1 | Hall 输入 + LED 数据输出 |
| **左边 (Left)** | 母头 (PinSocket) | 1×02 × 4 + 1×03 × 1 + 1×02 × 1 | PQ 信号 + LED (5V/Data/GND) + Touch |
| **右边 (Right)** | 母头 (PinSocket) | 1×02 × 4 + 1×03 × 1 + 1×02 × 1 | PQ 信号 + LED (5V/Data/GND) + Touch |

#### 拼接方式

**上下拼接（直接对插）：** 上方板的下边母头与下方板的上边公头直接插接，无需额外部件。

```
  板①下边 ♀♀♀♀♀ (PinSocket/母头)
           ↕ 直接对插
  板④上边 ♂♂♂♂♂ (PinHeader/公头)
```

**左右拼接（桥接件）：** 相邻板的左右两边均为母头，需要用一小截**双头公针**（直排针）作为桥接件插入两侧母头。

```
  板①右边 ♀♀ (母头) ──[1×02 直排针]── ♀♀ (母头) 板②左边
  板①右边 ♀♀♀(母头) ──[1×03 直排针]── ♀♀♀(母头) 板②左边
```

### 1.3 棋子与模具 (Stones & Molds)
*   **模型位置**: `stones/3d_prints/`
*   **文件格式**: `.f3d` (Fusion 360), `.gcode` (预切片打印文件)
*   **参考图片**: `stones/mold.jpeg`（模具）, `stones/stones.jpg`（成品棋子）
*   **背景知识**:
    *   **翻模灌浆**: 棋子是通过 3D 打印阳模 → 浇注硅胶阴模 → 灌注树脂的三步工艺制作的。
    *   **阳模与阴模的关系**:
        *   **阳模**（3D 打印件）= 棋子形状的"凸"模板，用来制作阴模，之后就不再需要。
        *   **阴模**（硅胶模具）= 实际浇铸用的"凹"模具，往凹坑里放磁铁、倒树脂即可生产棋子。
        *   为什么不直接 3D 打印凹模？因为硬塑料模具脱模困难（树脂会粘死），而硅胶柔软有弹性，掰一下棋子就弹出来，且可重复使用几百次。
        *   流程：`3D打印阳模（凸）→ 浇硅胶 → 硅胶阴模（凹）→ 浇树脂+磁铁 → 成品棋子`
    *   **磁铁嵌入**: 每颗棋子内埋一块钕磁铁（装在镀锌六角螺母中），用于霍尔传感器检测。
    *   **黑白区分**: 黑子和白子的磁铁**极性相反**，传感器通过正/负磁场区分颜色。
*   **软件**: **Fusion 360**, **切片软件 (PrusaSlicer/Bambu Studio)**。
*   **作用**: 设计棋子的形态以及用于批量生产棋子的模具。

#### 文件格式说明：STL vs G-code

| 格式 | 含义 | 类比 | 打开软件 |
| :--- | :--- | :--- | :--- |
| `.f3d` | Fusion 360 源文件，可导出 STL/STEP | 原始设计稿 | Fusion 360 |
| `.stl` | 3D 模型的形状描述（三角面片网格），与打印机无关 | 建筑设计图纸 | Fusion 360、PrusaSlicer、Bambu Studio、Cura、Windows 3D Viewer |
| `.gcode` | 打印机的逐行执行指令（喷头路径、温度、挤出量），针对**特定打印机和参数**生成 | 施工队的逐步施工指令 | PrusaSlicer、Bambu Studio、Cura（预览路径）；或直接发送给打印机 |

转换流程：`.f3d` → 导出 `.stl` → 切片软件 → `.gcode` → 打印机执行

| 场景 | 用哪个文件 |
| :--- | :--- |
| 你有 Prusa MK3S 打印机 | 直接用 `.gcode`，无需任何软件处理 |
| 你有其他型号打印机 | 用 `.f3d` 导出 STL，再用你打印机对应的切片软件生成 G-code |
| 发给代工厂打印 | 用 `.f3d` 导出 STL 发给厂商，厂商会用自己的切片软件处理 |

**从 Fusion 360 导出 STL 的步骤：**

1. 在左侧 BROWSER 面板中展开 **Bodies**，选中要导出的实体（如 `Body1`）。
2. 右键点击 → 选择 **Save As Mesh**（新版 Fusion 中此选项等同于导出 STL）。
3. 在弹出对话框中设置：
    *   **Format**: `STL (Binary)`（文件更小）
    *   **Refinement**: `High`（面片更细腻，打印效果更好）
4. 点击 **Save**，选择保存位置。

> 备选方式：顶部菜单 **File → Export** → Format 下拉选 **STL Files (*.stl)** → Save。

#### 制作步骤

> 以下步骤中，来自 `stones/README.md` 原始项目文件的内容标注为 **[原始]**，编者补充的操作细节标注为 **[建议]**。

**第一阶段：3D 打印阳模**

1. 用 Fusion 360 打开 `go_stones_mold.f3d`，或直接使用预切片的 `.gcode` 文件。
2. **打印参数**：材料 PETG **[原始]**，层高 **0.05mm** **[原始]**，填充率 15-20% **[建议]**。
3. 打印完成后打磨表面 **[原始：sand it]**。建议用细砂纸（400→800→1200 目）逐级打磨 **[建议]**。
4. 喷涂 **底漆/填充剂**（Primer/Filler），填平 3D 打印层纹，使表面光滑 **[原始]**。
5. 干燥后再次轻磨至满意的光洁度——阳模的表面质量直接决定棋子的最终手感 **[建议]**。

**第二阶段：浇注硅胶阴模**

1. 在阳模表面涂脱模剂（或凡士林薄层），防止硅胶粘连 **[建议]**。
2. 按照硅胶产品说明混合 A/B 组份，缓慢搅拌避免气泡 **[建议]**。
3. 将约 **130g** 硅胶缓慢浇注在阳模上，确保填满所有凹腔 **[原始]**。
4. 静置固化（一般 12-24 小时，取决于硅胶型号）**[建议]**。
5. 脱模，得到硅胶阴模——每个凹坑即为一颗棋子的形状。

**第三阶段：灌注树脂制作棋子**

1. **准备磁铁组件** **[原始]**：将 7×4mm N35 钕磁铁压入（或锤入）镀锌六角螺母 DIN 439 BM 8×1 中。
2. **⚠ 关键：磁极方向** **[原始]**
    * 黑子：磁铁 N 极朝上（传感器读数为负值，阈值 -40）
    * 白子：磁铁 S 极朝上（传感器读数为正值，阈值 +40）
    * 建议用记号笔在磁铁上标记方向，防止混淆 **[建议]**
3. **混合树脂** **[原始]**：按说明书比例混合环氧树脂 A/B 组份。黑子需额外加入 **5% 黑色色浆** **[原始]**。
4. **第一次灌注** **[原始]**：向硅胶模具每个凹坑注入 **0.3 ml** 树脂，形成棋子底层。
5. **放入磁铁** **[原始]**：待底层树脂稍微凝固（略有粘性但未完全固化）时 **[建议]**，将磁铁组件（螺母+磁铁）**按正确极性方向**放入凹坑中央。
6. **第二次灌注** **[原始]**：注入 **1.3 ml** 树脂，填满模具凹坑，将磁铁完全包裹。
7. **消除气泡** **[原始]**：用喷枪（或打火机快速掠过）加热树脂表面，气泡会自动破裂。
8. **固化**：室温静置至完全固化（通常 24 小时）**[建议]**。

**第四阶段：后处理**

1. 从硅胶模具中取出固化的棋子。
2. 打印 `stone_holder.f3d` 辅助夹具，在夹具孔中嵌入一颗磁铁——棋子会被磁力吸附固定，方便打磨 **[原始]**。
3. **湿磨** **[原始]**：用湿砂纸打磨棋子底面和边缘，去除毛刺和溢料。建议 400→800 目 **[建议]**。
4. **黑子特殊处理** **[原始]**：用异丙醇擦拭清洁，再涂少许抛光油增加光泽。
5. 成品每颗约 **3 克** **[原始]**，手感沉稳。

> **产量提示：** 19×19 棋盘需要至少 **361 颗棋子**（黑 181 + 白 180），建议每种多做 10-20 颗备用。按每副模具一次可做的数量估算批次。

**第一阶段详解：3D 打印阳模**

> 如果没有 3D 打印机 **[建议]**，可以在淘宝搜"3D 打印代工"或使用嘉立创3D打印/未来工场等线上服务，上传 `.f3d` 导出的 STL 文件即可。材料选 PETG **[原始：G-code 文件中指定 Prusament PETG]**，层高 0.05mm **[原始]**。填充率 15-20% **[建议]**。

1. 打印完成后，阳模表面会有明显的打印层纹。这些纹路会 1:1 复制到硅胶模具再转移到棋子上，所以**必须打磨光滑**。
2. 打磨顺序：400 目干磨去大纹路 → 800 目湿磨（砂纸蘸水）→ 1200 目湿磨抛光。
3. 喷 1-2 层底漆（每层薄喷，间隔 10 分钟），底漆会填平微小凹坑。
4. 底漆干透后（约 30 分钟），用 800 目砂纸轻轻湿磨一遍。
5. 用手指触摸，感觉完全光滑无颗粒感即可进入下一步。

**第二阶段详解：浇注硅胶阴模**

> 硅胶推荐 **[建议]**：淘宝搜"翻模硅胶 食品级"或"模具硅胶 半透明"，选择邵氏硬度 20-30A、操作时间 30-60 分钟、混合比例 1:1 的型号。原始项目仅指定品牌 Wagnersil Premium（德国产品），国内平替可选普斯顿、宏图、红叶等。

1. **涂脱模剂**：在阳模表面薄薄涂一层凡士林（药店有售），用棉签抹匀。没有凡士林可用食用油代替，但凡士林效果更好。
2. **围挡**：用硬纸板或乐高积木在阳模四周围一圈"围墙"（高于阳模最高点约 5mm），底部用热熔胶封住防漏。
3. **混合硅胶**：
   - 用电子秤按产品说明的比例（通常 A:B = 1:1 或 10:1）称量。
   - 沿同一方向缓慢搅拌 3-5 分钟，避免快速搅打产生气泡。
   - **消泡技巧**：搅拌好的硅胶从高处（约 30cm）细线状缓慢倒入另一个杯子，气泡会在拉丝过程中破裂。重复 2 次效果更佳。如果有真空泵更好，但不是必须。
4. **浇注**：从一个角落缓慢倒入硅胶，让它自然流动填满所有凹腔，不要直接倒在阳模凸起部分上方。
5. **固化**：放在水平桌面上，室温 20-25°C 静置。不同硅胶固化时间不同（12-24 小时），不要提前脱模。
6. **脱模**：从边缘轻轻掀起硅胶，慢慢与阳模分离。硅胶有弹性，不易撕破。

**第三阶段详解：灌注树脂制作棋子**

> 树脂推荐 **[建议]**：淘宝搜"水晶滴胶 环氧树脂"或"AB 胶 透明环氧"。选择固化时间 24 小时的慢干型（不要选 5 分钟速干型，操作时间太短）。原始项目使用德国品牌双组份环氧树脂（Epoxidharz），国内同类产品均可。

1. **准备磁铁组件**：
   - 将磁铁塞入螺母中孔。7mm 磁铁配 M8 螺母，手按即可压入，如果较紧可用平头螺丝刀轻推。
   - **判断磁极**：拿一块已知极性的磁铁靠近——同极相斥、异极相吸。用记号笔在所有磁铁的 N 极面画一个点。
   - 将黑子用的磁铁组件和白子用的分开放置（例如分两个盒子），避免混淆。
2. **混合树脂**：
   - 白子：按 A:B 比例混合透明树脂。
   - 黑子：先将 5% 黑色色浆加入 A 组份中搅匀，再加入 B 组份混合。
   - 每次混合量：建议一次做 20-30 颗（约 32-48ml 树脂），时间充裕不慌张。
3. **第一次灌注（0.3ml/坑）**：用一次性滴管吸取树脂，逐坑注入。不需要非常精确，目的是形成一层薄底。
4. **等待 2-4 小时**：让底层树脂从液态变为"果冻态"（用牙签戳表面，有粘性但不流动）。这个时机放入磁铁最理想——磁铁不会沉底，也能与上层树脂良好结合。
5. **放入磁铁组件**：螺母朝下（平面朝下），磁铁朝上。注意极性方向。
6. **第二次灌注（1.3ml/坑）**：填满凹坑，树脂液面与模具齐平。
7. **消泡**：热风枪距离 10cm 快速扫过表面（停留不超过 2 秒/处），或用打火机火焰快速掠过。气泡遇热会上浮破裂。
8. **固化**：盖一张纸防灰尘落入，室温静置 24 小时。不要移动模具。

**常见问题与解决**

| 问题 | 原因 | 解决方法 |
| :--- | :--- | :--- |
| 棋子表面有小气泡 | 树脂搅拌时带入空气 | 搅拌后静置 5 分钟再灌注；灌注后用热风枪消泡 |
| 棋子发黄/发雾 | 树脂受潮或 A/B 比例不准 | 严格按比例称量；树脂存放在干燥处 |
| 磁铁沉底偏位 | 第一次灌注后等待时间不够 | 等底层树脂变为果冻态再放磁铁 |
| 棋子粘在模具里取不出 | 硅胶模具表面不够光滑 | 灌注前在模具凹坑喷薄层脱模剂 |
| 黑子颜色不均匀 | 色浆没有充分搅匀 | 先将色浆与 A 组份单独搅拌 3 分钟 |
| 棋子厚薄不一致 | 灌注量不均匀 | 使用带刻度的滴管；灌注后检查液面齐平 |

### 第三步：联系厂商生产 (2.3)
当你准备好文件后，如何跟加工厂沟通？

#### A. PCB 生产与 SMT 贴片 (找嘉立创等厂商)
*   **推荐导出流程 (KiCad 一键导出)**:
    1.  **安装插件**: 在 KiCad 主界面的 `Plugin and Content Manager` 中安装 **Fabrication Toolkit**。
    2.  **一键生成**: 打开 `.kicad_pcb` 文件，点击工具栏插件图标 -> `Generate`。
    3.  **获取文件**: 插件会在项目下生成 `production/` 文件夹，包含：
        *   `*.zip`: **Gerber 文件**（裸板生产用）。
        *   `bom.csv`: **物料清单**（SMT 贴片用）。
        *   `positions.csv`: **坐标文件**（SMT 贴片用，即 CPL/POS）。
*   **核心生产参数**: 
    *   **层数 (Layers)**: 2层。
    *   **板厚 (Thickness)**: 1.6mm。
    *   **阻焊颜色 (Solder Mask)**: 强烈建议选**白色**（漫反射 LED 灯光，视觉效果更均匀）。
    *   **表面工艺**: 有铅/无铅喷锡或沉金均可。

#### B. 3D 打印 (找网上的打印服务)
*   **术语**: “我要打印这个零件，格式是 **STL** 或 **STEP**，材料用 **PETG** 或 **PLA**。”
*   **核心参数**: 
    *   **填充率 (Infill)**: 15%-20% 即可，受力件建议 40% 以上。
    *   **层高 (Layer Height)**: 0.2mm 是常规精度，0.1mm 是高精度。

#### C. CNC / 激光切割 (处理木材或亚克力)
*   **术语**: "请按照这个 **DXF** 文件进行**激光切割**（或 **CNC 铣削**），材料用 **5mm 厚的胡桃木板**（或亚克力）。"
*   **核心参数**:
    *   **切割 vs 雕刻**: 告诉师傅哪些线条是"切断"，哪些是"浅层雕刻"（如棋盘的网格线）。
    *   **比例单位**: 务必强调"单位是 **毫米 (mm)**"，防止厂商导入时比例缩放错误。

## 4. 整机组装指南 (Full Assembly Guide)

所有零件生产完成后，按以下顺序组装。

### 4.1 棋盘层叠结构 (Board Layer Stack-up)

棋盘由 4 层木板从下到上叠合而成，所有木板均通过 CNC 或激光切割（文件位于 `board/cnc_files/`）：

```
  ┌─────────────────────────────────┐
  │  ④ 顶层 Top (6.5mm 胶合板)     │  ← 棋盘表面，361 个 LED 透光孔，覆 0.6mm 木皮
  ├─────────────────────────────────┤
  │  ③ 网格层 Grid (6.5mm 胶合板)  │  ← LED 对准孔，透光显示网格线
  ├─────────────────────────────────┤
  │  ② 侧框 Side (10mm 胶合板)     │  ← 四周围框，形成内部空腔容纳电子元件
  ├─────────────────────────────────┤
  │  ① 底板 Bottom (5mm 胶合板)    │  ← 结构底板
  └─────────────────────────────────┘
```

### 4.2 组装步骤

#### 步骤一：木框粘合

1.  将**底板** (`bottom.dxf`)、**侧框** (`side.dxf`)、**网格层** (`grid.dxf`) 三层用木工胶粘合。
2.  夹紧，静置一夜等胶水完全固化。
3.  打磨接合面，确保平整。

#### 步骤二：3D 打印辅助件

打印以下零件（建议使用 PETG 材料）：

| 文件 | 用途 |
| :--- | :--- |
| `electronics/3d_prints/8x8_pcb_mask.f3d` | 8×8 PCB 遮光罩/固定件（×4） |
| `electronics/3d_prints/3x8_pcb_mask.f3d` | 3×8 PCB 遮光罩/固定件（×2） |
| `electronics/3d_prints/11x3_pcb_mask.f3d` | 11×3 PCB 遮光罩/固定件（×1） |
| `electronics/3d_prints/8x3_pcb_mask.f3d` | 8×3 PCB 遮光罩/固定件（×1） |
| `electronics/3d_prints/raspberry_pi_mount.f3d` | 树莓派固定支架（×1） |

PCB 遮光罩有双重作用：SMT 回流焊时保护另一面；组装时为 PCB 提供定位和支撑。

#### 步骤三：安装电子元件

按照 1.2 节的拼接布局图，将 8 块 PCB 子板装入木框空腔：

1.  **放置 PCB 遮光罩**到网格层下方对应位置。
2.  **安装 PCB 子板**，使用不锈钢螺丝固定（**必须用无磁性不锈钢**，避免干扰霍尔传感器）。
3.  **互联子板**：相邻子板通过边缘的排针/排母连接器（2.54mm 间距）对插：
    *   **Hall_top / Hall_bottom**：霍尔传感器信号，纵向相邻板之间。
    *   **PQ_side_a / PQ_side_b**：多路复用器控制信号，横向相邻板之间。
    *   **LedIn / LedOut**：LED 数据链路（Data, 5V, GND），在板间级联。
    *   **Touch_side_a / Touch_side_b**：触摸信号。
    *   **Power**：5V 电源分配。
4.  **安装 ESP32-S3**：插入其中一块 8×8 主板上的插座。
5.  **安装树莓派**：使用 3D 打印支架 (`raspberry_pi_mount.f3d`) 固定在空腔内（螺丝孔 3mm）。

#### 步骤四：供电接线

*   使用 **5V/10A (50W) 外部电源**。
*   通过端子台转接头接入侧板开孔，为 PCB 阵列和树莓派统一供电。
*   电源通过子板间的 Power 连接器在所有 8 块 PCB 之间分配。

#### 步骤五：安装顶层面板

1.  在顶层木板 (`top.dxf`) 表面贴合 **0.6mm 木皮**，用胶水粘合后熨烫压实。
2.  从内侧向 LED 孔中**灌入透明树脂**，保护 LED 并增强结构强度。
3.  涂刷 **4 层聚氨酯漆**（每层之间轻打磨）。
4.  使用 CNC 笔式绘图仪在表面**绘制棋盘网格线**。
5.  最终再涂一层聚氨酯漆保护网格线。
6.  将顶层面板固定到木框上。

#### 步骤六：制作棋子

1.  使用 `stones/3d_prints/go_stones_mold.f3d` 3D 打印硅胶模具。
2.  准备 7×4mm N35 钕磁铁，压入镀锌六角螺母（DIN 439 BM 8×1）中。
3.  将磁铁+螺母放入模具，灌入树脂，固化后脱模（每颗约 3g）。
4.  **关键：黑子和白子使用相反的磁极方向**，霍尔传感器通过正/负磁场区分棋子颜色。

### 4.3 功能验证

组装完成后，进行以下检查：

1.  **上电测试**：接通 5V 电源，确认 ESP32 和树莓派正常启动。
2.  **WiFi 连接**：连接到 ESP32 创建的 `saiboard` WiFi 网络。
3.  **传感器校准**：ESP32 启动时会进行 20 轮校准读数（`nr_of_boot_up_rounds = 20`），此时棋盘上不要放棋子。
4.  **LED 测试**：通过后端服务发送 LED 指令，确认 361 颗 LED 全部正常点亮。
5.  **棋子检测**：分别放置黑子和白子，确认传感器能正确区分（白子阈值 40，黑子阈值 -40）。
6.  **Web 界面**：浏览器访问 `192.168.4.5:8000`，确认 Flutter 界面正常加载并显示棋盘状态。
